# Night in Brainrot Valley — Roblox story-horror game

This repo is the design package for a Roblox game. No code exists yet.

- The full build brief is `roblox_horror_prompt.md`. When the user says to start (e.g. "start", "начинай", "Phase 0"), read it and ALL five documents it lists (`screenplay.md`, `cutscenes.md`, `lore.md`, `voice_lines.md`, `map.md` + `map_layout.png`) fully, then follow it phase by phase, stopping after each phase as it says.
- Do not start building on your own initiative before the user asks.
- `assets/audio/` and `assets/textures/` are original assets made for this game. Do not delete, rename or regenerate them.
- Talk to the user in Russian; code, comments and in-game text in English.
